## 使用方式

在新增或编辑活动页顶部，点击海报粘贴区后按 ⌘V / Ctrl+V，也可拖入或选择图片；粘贴完整活动正文，点击「自动填写下面的表单」。也支持仅提供正文。

结果进入现有可编辑表单。默认只补空白项，发起方的初始 `CMI Community` 可被素材中明确的组织名称替换。勾选「也更新已经填写的字段」才覆盖已填内容；没有识别到的字段不清空已有值。识别期间锁定表单，避免等待时的人工修改被结果覆盖。模型不能替换原海报、改变状态、活动 ID 或权限。

正文优先于海报，冲突由模型返回提示；没有明确年份、结束时间、地点或链接等应留空。两条已确认的补录活动继续保护日期和「该时间为后期补录」说明。自动结果仍可手改；只有管理员点击保存／发布才持久化活动内容。

当前没有模型 API 密钥，页面会如实提示「识别服务尚未配置」，手动填写可用。测试中的成功识别使用合成模型响应，不能据此宣称真实中文海报识别完成或达到准确率指标。

## 接入与数据边界

- 新增 `GET/POST /api/v1/admin/events/autofill`，要求已有 OTP 管理员会话；Agent Bearer 密钥不能替代登录。
- 服务端固定调用 Anthropic Messages API，以 JSON Schema 限制结构，再由 Zod 检查长度、日期、HTTPS 链接和字段。无工具调用、无用户 URL 抓取；素材指令不构成操作授权。
- 点击识别才发送当前海报和正文给 Claude。不发送邮箱、会话、其他活动、私有桶地址或整库；媒体先核对私有关系、状态、字节数及 SHA-256。模型密钥只在服务端请求头使用。
- 正文最多20000字，JSON请求64 KiB；返回128 KiB、输出预算3000 token、超时45秒。每位管理员一分钟最多5次请求。
- 自动识别图片限7 MiB、边长不超过8000像素，以满足模型的 base64 10 MB 限制。原手动上传10 MiB限制不变；过大图片保留并提示，不默默压缩／改写海报。
- 原始正文和模型响应不写活动表、修订或日志。只用现有本地限流表记录计数；人工点击保存后，原流程保存最终字段。没有新 migration 或依赖。
- 后台「API 授权」产生的是 Agent 调用官网的凭证，不是模型密钥，不能替代 Claude API 凭据。

本地密钥使用被 Git 忽略的 `.dev.vars` 中的 `ANTHROPIC_API_KEY`；可选 `EVENT_AUTOFILL_MODEL`，默认 `claude-haiku-5-5`。不要发到聊天或提交 Git；配置后重启服务并用真实素材核验。本次未创建模型账户、未新增付费服务、未发送真实模型请求。生产 Secret 和上线仍待批准。
