# Experiments

Experiment 保存“先验证再决定”的可撤销尝试。它不是开发日记，也不用于已经确定的普通任务。

## Naming and Status

- 文件名：`EXP-YYYY-NNN-short-slug.md`，NNN 每年从 001 递增。
- 状态：Planned、Running、Concluded、Abandoned。
- 每份记录必须关联 GitHub Issue，开始前写明基线、变量、成功和停止条件，结束后补充观察、结论和后续处理。

当前没有已登记 Experiment。新增记录时复制 [template.md](./template.md)，并在 Project Workpad 中登记运行中的实验。
