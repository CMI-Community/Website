## 当前接法

浏览器粘贴海报和已编辑正文 → 现有私有媒体上传 → 管理员会话保护的 `/api/v1/admin/events/autofill` → 服务端 OpenAI Responses API → 严格 JSON Schema 和本地 Zod 校验 → 可编辑表单 → 人工保存／发布。

默认模型为 `gpt-5.4-mini`，也支持该系列的日期快照。请求使用图片 data URL、`detail: high`、严格结构化输出、`reasoning.effort: none`、`max_output_tokens: 3000` 和 `store: false`。

默认只补空白字段，显式勾选才更新已填内容；未知值不清空已有内容。识别期间锁住人工表单，结果不会改动发布状态或海报ID。两条补录活动的日期及说明继续受保护。缺失结束时间留空，图文冲突优先正文并提示。接口逐项检查字段格式，保留有效结果，把无效值留空并提示人工核对。

输入正文最多20000字、JSON请求64 KiB；私有海报沿用10 MiB上限及既有尺寸／结构校验，再回读核对长度和 SHA-256。去除早期 Claude 原型专属7 MiB限制。每位管理员一分钟最多5次，45秒超时，模型响应最多128 KiB。缺密钥、权限不足、额度不足、拒绝、截断或格式错误均提示中文错误并保留表单和素材。

模型密钥只由服务端环境变量 `OPENAI_API_KEY` 提供；可选 `EVENT_AUTOFILL_MODEL`。示例文件只有空值，真实凭据不进入源码、浏览器或Git。原始正文／模型结果不写日志或活动表；只有人工保存才使用现有修订流程持久化字段。后台「API授权」签发的 Agent 密钥不能代替模型 API 密钥。

官方依据：[GPT-5.4 Mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)、[Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)、[结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs)、[图片输入](https://developers.openai.com/api/docs/guides/images-vision)。模型选型历史保留在 [11月1日调研说明](./活动后台自动填写_模型调研与实施说明_2026-11-01.md)，当前实际服务以本记录为准。
