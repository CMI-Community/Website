## Changes

- React Router 全栈、TypeScript、Cloudflare Worker、D1、R2 和 Node.js 24 长期平台地基上线。
- 海报墙迁入 `poster-wall` 模块，根路径暂时 308 到 `/archive/posters`。
- Apache-2.0、品牌边界、贡献、安全、CI、staging 自动部署和 production 人工批准启用。
- 邀请制 Better Auth、Google/GitHub OAuth、服务端角色和内容/媒体接口地基可运行。

## Data and Migration

- `VERIFIED`：180 张优化 WebP 和公共白名单目录进入 R2，180/180 资产可访问。
- `VERIFIED`：3 条留言与 2 条投票迁入新 D1 并保持匿名访客行为。
- `VERIFIED`：首位管理员身份、profile 和审计记录建立后，一次性 bootstrap Secret 已删除。

## Known Issues

- 当前根路径仍呈现海报档案，不是真正官网首页。
- 完整登录页、用户中心、CMS 后台、公开注册和社区关系功能不在本版本。

## Rollback

若核心生产验收失败，将 `cmi.community` 和 `www` 重新绑定旧 `cmi-community-site` Worker。旧 Worker、旧反馈 D1、新 D1 和 R2 在观察期不删除；回滚后核对留言数据写入窗口，再决定向前迁移。详细步骤见 [release-and-rollback.md](../operations/release-and-rollback.md)。
