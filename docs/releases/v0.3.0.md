## Changes

- 首页顶部与吸顶导航共用 Projects 面板，明确展示“WaytoAGI 切磋大会 · 清迈场 → 第 27 / 26 期”两级关系；第 26 期为站内入口，第 27 期保留公众号外链。
- WaytoAGI 第 26 期“博物馆奇妙日”原生迁入 CMI React Router SSR，提供中、英、泰三语项目页和回顾、只读档案、详情与 1080×1350 纹样卡导出；首页不加载兰纳项目包。
- 首页标题与 Museum 入口之间增加近期活动横向海报区，发布《牛来》观影、新云南市场义卖和第 27 期即兴戏剧 + AI 短剧共创；支持指针 3D、放大层、详情外链、键盘焦点和 390px 横向浏览。
- 活动按清迈时区开始时间从近到远排列，达到开始时刻后自动从近期区移入 Event Museum；Discord 保留为普通社交入口，不再作为吸顶强调入口。
