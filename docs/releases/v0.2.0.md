## Changes

- `cmi.community/` 从跳转海报档案改为 Community Hero、Photo Museum、Event Museum 组成的正式首页。
- 首屏放大并收紧手机字号/字距，加入由 CMI 彩色 Logo 延展的低对比模糊色场。
- Photo Museum 以七条交替方向轨道展示 528 张照片，支持暂停、reduced motion、全屏原比例浏览、键盘与触摸切换。
- Event Museum 继续复用现有 180 张海报、LOFI、翻转、详情和公共留言体验；`/archive/posters` 保持独立入口。
- 首页与海报档案统一 Discord、Bilibili、公众号、小红书、Reddit、GitHub 和微信联系入口。

## Data and Migration

- 无 D1 migration，无用户数据结构变更。
- production R2 `cmi-community-public-assets/photo-museum/v2/` 增加 528 条公开目录记录和 1056 个 WebP；墙面缩略图长边最大 720px，全屏图长边最大 2560px。
- 508 个新私有素材中排除 7 个与 v1 精确重复项；原图、源文件名、本机路径和授权材料不进入公开仓库或目录。
- v2 目录与资产版本化保留；发布和回滚均不删除 R2 对象。
