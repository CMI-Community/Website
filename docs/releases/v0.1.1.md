## Changes

- 建立根级公开协作入口、唯一 Project Workpad 和任务/思考/过程三位一体协议。
- 建立 T1/T2/T3 分级、ADR/Experiment/Release Record 索引与模板。
- 建立 Issue forms、PR 合同、Milestone 和任务/领域/状态/优先级标签。
- `check:trace` 进入 required `foundation`，阻止缺少任务、记录等级、必要决策、验证、回滚或上下文声明的人工 PR。
- 扩展公共边界扫描，阻止本机路径、OAuth code、非公共邮箱、明显个人数据和 production 导出。

## Data and Migration

无 D1 migration、R2 资产同步、production 数据写入或用户数据变化。`v0.1.0-foundation` 的 180 张海报、3 条留言、2 条投票和身份数据不受影响。

## Known Issues

- 自动检查能防止结构遗漏，不能判断记录内容是否真实；维护者仍需复核证据和结论。
- GitHub App 当前没有在组织仓库创建 Issue/PR 的权限，本次通过已验证的维护者 GitHub CLI 完成；不影响公开贡献流程。

## Rollback

本版本没有 production 运行时变化。若门禁误阻协作，维护者先使用 `trace:override` 并关联补录 Issue；若检查器本身有缺陷，通过 revert PR 撤回 CI 步骤。Issue、ADR、PR、Release Record 和失败证据继续保留，不删除历史。
