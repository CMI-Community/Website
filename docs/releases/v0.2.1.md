## Incident and Root Cause

- `cmi.community` 被旧目录 `CMI 海报工程/poster-wall` 中的 `cmi-community-site` Worker 误发布覆盖。
- 根因是发布前没有先确认新官网仓库、正确 production Worker 和三屏首页验收合同。
- 发现后创建 Issue #16，并从本仓库 `main` 使用 `env.production` 恢复 `cmi-community-platform`，没有迁移或删除 D1/R2 数据。

## Changes

- 保持 Community Hero、Photo Museum、Event Museum 三屏正式首页以及独立 `/archive/posters`。
- 将共享小红书入口更新为 `https://xhslink.cn/m/3C1MCJgpWq6`，同时覆盖首页与海报档案。
