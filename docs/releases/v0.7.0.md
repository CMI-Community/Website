## Changes

官网首页和吸顶导航增加 Blog。管理员可在富文本编辑器撰写、粘贴公众号图文、上传照片、预览、保存草稿和发布，并补填原来的发布日期。作者在独立名单维护，停用作者的已发文章保留署名。文章可以关联系列、活动和照片。系列和活动页会展示对应文章，关联活动的文章也会出现在该活动所属的公开系列。

读者可以按需阅读中英全文译文。标题、摘要、正文、图片说明和替代文字随语言切换，图片、链接地址和富文本结构保留。译文按公开修订缓存，仅向模型提供已公开的文字。公众号链接导入只在 staging 开放，生产可用编辑器的图文粘贴流程。

## Data and Migration

生产 D1 已应用并回读 `0007_add_blog.sql`，新增作者、文章、公开修订、媒体、关联与翻译缓存表。博客图片使用既有私有 R2，公开读取按当前文章修订校验。变更向前兼容上一版 Worker。生产迁移前已记录 D1 Time Travel 恢复点和上一 Worker 版本，恢复点保存在本地发布证据。

## Configuration

已回读生产 Worker 的 `BLOG_OPENAI_API_KEY` 与活动自动填写的 `OPENAI_API_KEY` 绑定。`BLOG_TRANSLATION_DAILY_LIMIT` 控制每个环境的新翻译分段额度。生产 Worker 按默认规则关闭链接导入，运行版本没有 `BLOG_WECHAT_IMPORT_ENABLED` 覆盖配置。
