## Changes

照片放大层受动态视口约束，支持关闭、前后切换、触摸、键盘和焦点/页面滚动恢复。后台提供照片上传、筛选、发布与下架，活动缩略图总览、搜索与历史海报编辑，以及系列栏目 Logo、介绍和活动/照片归属。公开 `/series` 与栏目详情可以按持续系列浏览内容。

首页主体仍保留既有三屏结构；这次没有实施完整首页重设计。原工具导航、合作须知和已有活动继续保留。

## Rollback

新表及原对象保留，不把代码回退当作数据回退。若上线后新增下架状态，旧 Worker 可能忽略覆盖层而重新展示内容；优先部署兼容修复，回退前逐项核对可见性。数据库恢复需要明确评估切换后新增内容，不能直接覆盖最新业务数据。

旧公共资源域名直链、外部缓存和已下载文件不会因官网下架撤回。新上传照片暂沿用原图作缩略尺寸预览；照片直接活动关联限 D1 活动，历史活动可通过系列关联。隐藏系列不级联隐藏活动和照片。
