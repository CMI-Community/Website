## Changes

首页 Event Museum 与完整海报档案默认按可靠活动时间倒序，从未来到过去，同步向上滚动。可独立切换时间正序、随机、色彩排序及差速滚动；保留方向、流速、暂停、翻转墙与详情。缺少可靠活动时间的旧海报回退到发布日期，补录占位不冒充实际举办时间。近期活动时间线继续使用原有生命周期规则。

随机排序保留当前顺序，点击“重新打乱”才生成新排列。色彩排序按需提取图片实际像素的主色及主要色彩，按红到紫排列，再接白／灰／黑；显示分析进度、缓存与失败重试。历史海报使用当前发布目录白名单限定的同域只读图片入口，不接受任意远端地址。

依赖审计原先被 picomatch 告警阻塞；使用保留上游源码、MIT 许可及来源的私有本地修补，限制危险的单分支重复 extglob。没有关闭审计或降低测试版本。详细语义限制和替换条件见 ADR 0014；这不是官方修复版本。

## Known Issues

- 色彩按 48×48 像素采样及主要彩色色簇近似分类；多色海报和中性底色可能按局部主色进入色谱，不等于人工审美判断。首次选择需等待分析，结果在当前会话复用。
- 本地 picomatch fork 需要维护。上游发布可验证完整修复后应替换并重跑攻击与构建兼容检查。
- v0.5.0 遗留的真实生产后台 OTP 操作验收仍属独立范围，本轮公开界面验收不替代它。
