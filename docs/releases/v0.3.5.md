## Changes

- 新增可单独分享的 [CMI 活动合作须知](https://cmi.community/cooperation)，保留已确认的六条正文与“讨论稿 · 供合作沟通使用”标识。第 4 条说明平等对话、主理人接受追问和修正、参与者之间的交流及独立判断。
- 首页近期活动之后增加入口。独立页沿用官网字体与底色，提供六节目录、可直接刷新的锚点、键盘跳到正文、返回首页和打印样式；无 JavaScript 时正文仍完整可读。
- 为通过既有安全门禁，更新 Better Auth 1.7.15、Zod 4.6.7、Vite 8.3.5、Vitest 4.1.12 及兼容传递依赖。生产依赖审计为 0。Better Auth 1.7 会屏蔽数据库钩子的注册拒绝响应，因此在端点 before hook 保留原有邀请制 403 契约，数据库钩子继续保护其他身份创建路径；E2E 同时验证拒绝后账号数量为 0。
- 菜单键盘测试等待真实展开状态，避免客户端挂载前按键丢失。生成截图加入 lint 忽略范围，运行源码仍完整检查。
- package 版本从 0.3.4 更新为 0.3.5。本地尚未上线的活动后台分支不在本次运行提交中。

## Data and Migration

- 无新增 D1 migration；staging 与 production workflow 均返回 `No migrations to apply`。
- 无 R2 业务对象写入、数据导入、公共 API、权限模型、OAuth 或 Secret 变更。构建资产由现有 Worker 发布流程更新。
- 页面与截图验收使用公开 GET/HEAD，不创建生产留言、账号或其他业务资料。
