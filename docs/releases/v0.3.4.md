## Changes

- 将 2026-09-26 18:00–20:00《把清迈过成家》从旧记录的 CMI TALK #14 原位纠正为正式推文确认的 CMI TALK #13，并替换标题、期次、详情链接、摘要和总览海报，不新增重复活动。
- 新增 2026-10-04 17:30–19:30《明月照他乡｜大人观影 × 小小文化家》，以一场双路线活动建模：大人观看复旦大学纪录片《明月照他乡》并交流，5–12 岁儿童参与“小小文化家”文化分享与《庄子》体验。
- 两场活动继续由统一活动目录按清迈时间自动投影为即将、进行中或已完成，并进入 Event Museum。
- 远端验收将媒体密集首页的导航收束为 `domcontentloaded`，对横向固定导航使用明确的链接激活和目标滚动，不再把 528 张照片的整页 `load` 时间当作业务失败。
- package 版本从 0.3.3 更新为 0.3.4。
