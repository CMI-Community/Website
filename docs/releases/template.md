# Release TAG

- 状态：Released
- 日期：YYYY-MM-DD
- Tag：TAG
- Commit：COMMIT
- GitHub Release：URL
- 关联 Issue/PR：#N / #N
- Runtime impact：production / none

## Changes

说明本版本对用户、开发者和平台的实际影响。

## Data and Migration

记录 migration、数据数量、资产同步和兼容窗口；没有变化时明确写“无”。

## Configuration

只记录配置项和 Secret 名称，不记录值。

## Verification

- `VERIFIED`：检查、结果与持久证据链接。

## Known Issues

- 无，或列出影响、状态和跟踪 Issue。

## Rollback

写明回滚版本、资源、数据窗口和验收步骤。
