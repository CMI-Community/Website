## Changes

- 首页“最近，可以一起做什么”改为双侧连续时间线：左侧展示“进行中 / 即将举行”，右侧展示“已完成”，中间以 `NOW / 现在` 分隔。
- 活动生命周期改为以 `startsAt` / `endsAt` 判定三态；活动结束后立即进入右侧时间线和 Event Museum，不再在开始时刻提前归档。
- 左侧最多展示 5 场；右侧默认展示最近 5 场，并保证结束未满 24 小时的活动继续可见。两侧均按距离当前时间从近到远排列。
- 保留既有海报 3D、点击放大、详情新窗口、键盘焦点恢复、减少动画和 390px 横向浏览；分组为空时显示紧凑空状态。
