# ADR 0013：活动海报按时间浏览与独立滚动方式

- 状态：Accepted
- 日期：2026-11-18
- 关联 Issue：[#60](https://github.com/CMI-Community/Website/issues/60)
- Supersedes：[ADR 0009](./0009-recent-activity-timeline.md) 第 4 条中 Event Museum 仅接收已结束活动的限制；近期时间线规则继续有效。

## 上下文

VERIFIED：当前公共海报投影只收录已结束的受管活动，墙内又按微信发布日期排序。OBSERVED：发布日期为空的受管活动无法正确排入历史；各轨负延迟与差速使时间排序不能形成整体浏览。维护者要求默认从未来到过去，并可在同步与差速滚动之间选择。

## 决策

1. Event Museum 展示全部已发布、媒体已核验的活动以及已公开历史海报，不按活动是否结束过滤。首页近期时间线的状态、分组与数量规则继续使用 ADR 0009。未发布、下架、媒体不可用记录继续由原服务端查询隐藏。
2. 使用公开投影已有的完整活动日期及清迈时间作为排序依据。无法确认完整活动日期、仅有年份、补录占位或无效日期时回退到可靠发布日期；没有日期的记录放在末尾。不从标题或自由描述中猜测日期，不添加公开管理字段。
3. 默认时间倒序，另可选时间正序。同步与差速作为独立于排序的浏览方式；默认同步向上滚动。同步使用一个动画轨道承载整组有序海报，统一位移、速度和暂停。差速保留已有分轨效果。
4. 首页嵌入与完整档案复用同一组件，保留方向、速度、暂停、详情及翻转显示。选择只作用于当前组件会话。

## 备选方案与后果

只调整各轨动画时长，仍会因长度和偏移不同产生相对位移，未采用。改为单轨整组动画能够保持海报之间相对位置，代价是增加一种布局。历史缺失日期仍影响绝对时间精度，不能靠排序补全事实。

## 迁移与回滚

无数据库迁移、媒体写入、权限或 Secret 变化。公共 DTO 字段保持。按既有流程交付候选与发布，回滚恢复旧代码即可；不会删除活动或历史资料。

## 推翻条件

以后引入经人工核实的历史活动日期字段时，用新 ADR 更新排序来源和公开投影。
