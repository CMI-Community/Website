# ADR 0001：官网采用全栈平台地基

- 状态：Accepted
- 日期：2026-08-07

## 决策

复用 `CMI-Community/Website` 的初始化历史，在干净工作副本中采用 React Router 全栈、TypeScript、Cloudflare Workers、D1 和 R2。现有海报工程保持私有归档源，只选择性迁移可公开的模块代码与经过白名单清洗的数据。

## 原因

官网未来需要服务端身份、角色、内容发布、媒体、审计和社区实验；纯 SPA 占位仓库不能提供这些边界。Cloudflare 运行时可以让 SSR、认证、D1 与 R2 在同一部署单元内工作，同时保留按领域拆分的内部模块。

## 约束

- 根路径在新首页完成前 308 到 `/archive/posters`。
- 原始归档、原图、SQLite、后台记录和生成输出不进入公开 Git 历史。
- 运营内容以 D1 为唯一发布源；代码仓库不复制一份 CMS 内容。
- 生产发布由受保护环境人工批准，旧部署在观察期可回滚。
