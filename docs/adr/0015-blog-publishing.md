# ADR 0015：官网博客、署名与公开译文

- 状态：Accepted
- 日期：2026-11-21
- 关联 Issue：[Website #65](https://github.com/CMI-Community/Website/issues/65)

## 决策

- 后台沿用管理员邮箱 OTP 和同源检查。博客作者是独立署名档案，记录显示名和启用状态。
- D1 保存草稿、不可变的公开修订、审计和文章关系。公开路由只能读取当前公开修订。补填日期仅供显示和排序，状态由管理员操作。使用独立新增表，原活动及照片表继续作为关系目标。
- 公开系列聚合直接关联和当前公开活动的所属系列。历史活动以现有公开海报档案的 ID 为准。公开照片继续检查图库及其活动的可见性。正文上传的图片使用私有 R2，并通过当前公开修订验证读取。
- 富文本粘贴与公众号导入共用受限文档结构。公众号链接导入先在 staging 验收，通过两篇真实文章（含一篇多图长文）后单独开放生产入口；收到验证页时回到粘贴。微信原生组件用原文链接保留位置。
- 公开页面按需中英互译。服务端按公开修订缓存结构化文本，生成阶段使用原文作为阅读内容。模型凭证由 Worker Secret 配置，公开接口先检查修订和使用额度。

## 运行配置

- `BLOG_OPENAI_API_KEY` 是博客 Worker 的服务端密钥。staging 先配置独立绑定并验证中英全文生成、缓存命中与重试。production 从同名 GitHub 环境 Secret 随受保护的 Worker 部署上传。模型只收到已经公开的文字段落、标题和图注。
- `BLOG_TRANSLATION_DAILY_LIMIT` 控制每个环境每日可启动的翻译分段数，默认 120，按 UTC 日统计。读已有译文无需模型额度。
- `BLOG_WECHAT_IMPORT_ENABLED` 是后续开放生产链接导入的开关。staging 用真实文章验证后再启用；富文本粘贴可独立使用。

## 迁移与回滚

先运行向前兼容的新增表迁移，再切换 Worker。回滚启用上一个 Worker 版本，保留已写入的博客表和媒体。恢复服务前核对博客修订和 R2 读取。
