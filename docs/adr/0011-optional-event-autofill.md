# ADR 0011：可选海报与正文自动填表

- 状态：Accepted
- 日期：2026-11-01
- 授权：负责人在本地验收时明确新增自动填写并保留手动填写，不涉及上线授权。

## 决策

在表单上方添加图片粘贴／选择和正文输入，通过多模态模型产生建议。不得直接保存、发布或改变权限；默认补空白项，覆盖已有字段由管理员显式选择。正文优先，缺失留空，冲突提示；补录规则继续受保护。

本地先以 Claude Haiku 5.5 为候选，服务端调用 Messages API 并要求结构化 JSON，再独立校验结果。最终模型质量待真实素材评测。无密钥时显示未配置，手动表单仍可用。当前只做单个服务适配。

仅已有 OTP 管理员会话能使用，不扩展 Agent 密钥权限。模型只收到当前海报和正文，密钥留在服务端；不保存原始素材／模型结果到日志或活动记录。沿用私有媒体与人工保存流程，无新增 migration。

## 验证与限制

隔离本地数据和模拟模型响应用于接口／界面验证；没有凭据时不得宣称真实识别完成。真实质量、额度及延迟需在安全配置后验证。保持不部署、不推送、不写线上资源。

实现与来源见 [调研及实施说明](../活动后台自动填写_模型调研与实施说明_2026-11-01.md)。

## 2026-11-06 服务选择更新

负责人已选择 OpenAI GPT-5.4 Mini；本地适配改为 OpenAI Responses API、图片输入与严格结构化结果。此前 Claude 仅为未配置密钥的原型候选，不再作为运行服务。人工核对、权限、补录和不上线边界保持原决策。密钥创建／写入仍待本地保存授权，真实调用尚未验收；详见 [OpenAI接入记录](../活动后台自动填写_OpenAI接入记录_2026-11-06.md)。
