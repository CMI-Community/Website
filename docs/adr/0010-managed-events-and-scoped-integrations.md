# ADR 0010：D1 活动后台与限定范围的机器授权

- 状态：Accepted
- 日期：2026-11-01
- 依据：内容负责人确认的手填版与 v3 方案，以及本次本地实施授权；线上发布仍未授权。

## 决策

10 场活动迁入 D1，继续复用内容、修订、审计与身份表，独立保存活动结构、外部映射、幂等和迁移证据。180 张历史海报维持只读。管理员采用配置的唯一邮箱与 OTP 会话，API 密钥仅存哈希，默认草稿写入和上传、7 天过期，支持来源或指定活动范围。

公开首页、档案和 API 统一投影 D1；受管图片只从私有桶经发布关系校验后返回，禁止缓存。通用内容/媒体接口不允许绕过活动接口。事务内检查版本、授权和来源版本，写入修订、审计及幂等结果；下架追加独立恢复记录，失败时不报告完整成功。

两场指定存量活动采用 2026-07-10 补录日期和空时段，简介追加指定文字，原日期保留。新增活动必须真实起止时间。每日私有备份与每月加密离线副本、隔离恢复演练见[操作单](../operations/events-admin-launch-runbook.md)。

## 影响和上线门槛

新增 D1 schema、私有桶与 Secret；部署前必须完成真实媒体复制校验、旧公开入口撤除和缓存清理。未完成时迁移媒体为 pending，公开查询关闭对应活动。原始资料和旧迁移不删除。只回滚 Worker 不能恢复数据或保证继续下架。

## 当前状态

本地实现与测试，未 push、未合并、未部署、未执行线上迁移；实施结果由本次报告记录，历史生产 Release Record 保持原样。
