# ADR 0016 博客封面、头图与永久短链接

- 状态：Proposed
- 日期：2026-11-26
- 关联 Issue：[Website #65](https://github.com/CMI-Community/Website/issues/65)

## 决策

- 博客使用 `/b/<编号>` 作为公开和分享地址。D1 为新建和已有文章分配唯一数字编号。文章标题、正文、发布日期、版本和上下架操作共用该编号。
- 旧文章地址在文章公开期间以 HTTP 308 跳转，保留查询参数。查询、译文和图片以当前公开修订为准。旧译文 API 与已分享的正文图片地址仍可使用。
- 封面和头图分别写入公开修订，编辑器草稿可以先行替换或共用。图片使用现有私有 R2 与修订关联。博客列表依次选用专用封面、头图或首张已公开的正文上传图，正文头图由编辑器明确设置。读者可以点击头图查看上传原图。
- 列表以 16:9 图框排列单列横卡，窄屏图在文字上方。正文头图用上传尺寸和原比例显示，摘要缺省时用首段正文作为列表预览。

## 迁移与回滚

`0008_add_blog_presentation_and_links.sql` 增加编号表、为现存文章分配编号，并在公开修订加入可空图片引用。旧 Worker 仍可插入和读取既有列。恢复到 v0.7.0 时，旧文章地址可继续读，短链接与专用头图需恢复带该功能的 Worker 才可访问。保留分配过的编号、公开修订和 R2 对象。
